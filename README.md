# 🎯 ITMO Tracker

**Отслеживание позиции в конкурсных списках ИТМО в реальном времени.**

Парсит списки для **бакалавриата** и **магистратуруы**.

---

## ✨ Возможности

- ✅ **Автоматический парсинг** конкурсных списков в заданный интервал времени
- ✅ **Оценка возможностей поступления** с учетом положения в списке на сайте и приоритетов
- ✅ **Анализ конкурентов** — кто уйдет на другую программу, кто останется
- ✅ **График изменения позиции** во времени по историческим данным
- ✅ **Системные уведомления** при изменении позиции или статуса
- ✅ **Веб-интерфейс** с полной аналитикой
- ✅ **Фоновый режим** — программа работает в трее
