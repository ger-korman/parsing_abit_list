# 🎯 ITMO Tracker

**Отслеживание позиции в конкурсных списках ИТМО в реальном времени.**

Парсит списки для **бакалавриата** и **магистратуруы**.

---

## ✨ Возможности

- ✅ **Автоматический парсинг** конкурсных списков в заданный интервал времени
- ✅ **Оценка возможностей поступления** с учетом положения в списке на сайте и приоритетов
- ✅ **Анализ конкурентов** — кто уйдет на другую программу, кто останется
- ✅ **График изменения позиции** во времени по историческим данным
- ✅ **Системные уведомления** при изменении позиции или статуса
- ✅ **Веб-интерфейс** с полной аналитикой
- ✅ **Фоновый режим** — программа работает в трее

---

## 📦 Установка

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/your-username/itmo-tracker.git
cd itmo-tracker
```

### 2. Установите зависимости
```bash
pip install -r requirements.txt
```
### 3. Установите Playwright (для парсинга)
```bash
playwright install chromium
```
## ⚙️ Настройка

Отредактируйте файл config.py:
```
USER_ID = "1234567"  # Ваш sspvo_id
CHECK_INTERVAL = 15  # Минут между проверками

Где найти sspvo_id: в конкурсном списке найдите себя -> номер типа №1871234 -> берите число.
```

---

## 🚀 Запуск
```
python main.py
```

После запуска:
- Откроется веб-интерфейс (http://localhost:5000)
- Парсер будет проверять позицию каждые заданные N минут
- При изменении позиции придет системное уведомление

## ❓ FAQ

#### Почему не загружается список?
Парсер не работает с включенным VPN, проверьте подключение, сделайте туннелирование или выключите VPN для корректной работы парсера.

#### Хранит ли программа персональные данные?
Нет. Программа обрабатывает анонимизированные открытые данные с сайта ИТМО. Парсер скачивает JSON-файлы с конкурсными списками по каждой программе.
